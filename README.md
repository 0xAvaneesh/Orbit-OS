# ORBIT OS

ORBIT OS is a web based desktop I made for the Hack Club WebOS project.

I wanted to make something that feels like an actual desktop instead of just a normal webpage.

## What it has

* Draggable windows
* Files
* Notes
* Calculator
* Browser
* Terminal
* Settings
* Working clock
* Dock
* Dark glassy UI
* Space background

The calculator and some of the terminal commands actually work too.

## Made with

HTML, CSS and JavaScript.

I didn't use any frameworks for it.

## How to run it

Just open `index.html` in a browser.

## Why I made it

This is mainly a project for learning how desktop interfaces and web apps work while making something I actually like.

I'll keep adding things to ORBIT OS as I work on it.

Made for Hack Club WebOS.
